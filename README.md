## Описание проекта
Приложение с графическим интерфейсом для ведения библиотеки просмотренных фильмов. Вы можете добавлять названия, жанры, год выпуска и оценки, а также фильтровать список.

## Особенности работы с файлами
* Локальная база данных хранится в файле `movies.json`.
* Если файла нет при запуске, он будет создан автоматически при первом сохранении.

## Инструкция по запуску
1. Убедитесь, что установлен Python 3.7 или новее.
2. Откройте папку с проектом в терминале.
3. Запустите приложение:
   ```bash
   python main.py
